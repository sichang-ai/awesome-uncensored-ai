# 角色卡怎么写

角色卡是你交给模型的一张人物设定表。写得好，角色能演一整晚不出戏；写得差，聊三轮就变回那个万能的、谁都像的助手腔。

好消息是这套字段是通用的。SillyTavern（中文社区叫「酒馆」）定下的 V2/V3 字段格式，思畅、Chub 等平台都兼容——**学一次，到处能用**，角色卡还能带着走。

## 字段各管什么

不必每个都填。先弄清哪个字段实际影响什么，再决定把力气花在哪。

| 字段 | 它实际影响什么 |
|---|---|
| `description` | 身份与外在。**模型每一轮都看得到**，最重要的信息放这里 |
| `personality` | 性格。决定角色怎么反应 |
| `scenario` | 当前处境。决定这场戏从哪开始 |
| `first_mes` | 开场白。**定下整段对话的文风与节奏**——单个字段里影响最大的 |
| `mes_example` | 对话示例。教模型怎么说话，比任何形容词都有效 |
| `system_prompt` | 系统指令。全局规则，比如叙述用第几人称 |
| `post_history_instructions` | 插在对话历史之后的指令。**位置靠后所以权重高**，适合放最容易被聊忘的硬规则 |
| `alternate_greetings` | 备选开场白。同一个角色的不同入口 |
| `character_book` | 世界书。见[世界书指南](lorebook.md) |

新手常犯的分配错误：把 80% 的字数堆在 `description` 里写背景故事，`first_mes` 一句「你好，有什么可以帮你？」。实际效果正相反——背景故事模型多半用不上，开场白才是它模仿的样板。

## 三个最常见的失败模式

这一节比字段表重要。绝大多数「角色不像」的问题都是下面三条之一。

### 一、人设写成了形容词

❌ 「温柔善良，善解人意，很会照顾人。」

模型无从下手，只能演成一个通用好人——和它默认的助手人格几乎没区别。

✅ 「说话总是先停顿半拍，习惯用问句代替否定——不说『不行』，说『你确定要这样吗』。」

区别在于：**形容词是你对角色的评价，行为才是角色本身。** 写模型能直接照做的东西。

### 二、只写「不做什么」

❌ 「不会生气，不说脏话，不主动提起过去。」

这是反直觉的一条：**你越强调不要什么，模型的注意力越被吸到那些词上**，反而更容易踩。「不要想大象」的老问题。

✅ 「情绪上来时会突然变得非常客气。」

把否定翻译成它的正面表现。「不会生气」背后你真正想要的是某种反应方式——直接把那个方式写出来。

### 三、开场白没给戏

❌ 「你好，我是林医生，有什么可以帮你？」

没场景、没情绪、没话头。用户只能回一句「你好」，然后两边一起卡住。

✅ 「（她把病历合上，指尖在封面上敲了两下）你迟到了四十分钟。上一次你说会准时的时候，我信了。」

这一句给了四样东西：**场景**（诊室、病历）、**动作**（敲封面——一个可被模仿的小动作）、**情绪**（压着的不满）、**必须回应的话头**（一句指控，用户不接都不行）。

开场白同时也是文风样板。你用括号写动作，模型接下来就用括号写动作；你写短句，它就写短句。**想要什么文风，开场白就先写成什么样。**

## 可直接套用的模板

```
【身份】谁，什么处境，和用户什么关系
【说话方式】句子长短、口头禅、回避什么话题、情绪上来时怎么变
【行为习惯】3 条具体的、看得见的动作
【当前场景】此刻在哪，正在发生什么，有什么悬而未决
【开场白】一段话：给场景、给情绪、留一个用户能接的话头
```

填好的样子：

```
【身份】沈砚，三十四岁，旧书店「停云」的店主。你是这家店唯一还会来的常客，
最近两个月每周三来一次，从不买书。他不知道你为什么来，也没问过。

【说话方式】句子偏短，很少用感叹号。不接直白的夸奖，会岔开。
提到具体的书时话会突然变多，说完自己意识到，然后停住。
被问及私事时用陈述句回避——不说「我不想说」，而说「这个不重要」。

【行为习惯】
- 说话时手上总在做别的事：擦封面、码书脊、拧笔帽
- 想事情的时候会用食指关节敲桌面，两下一停
- 递东西永远是双手，哪怕只是一张便签

【当前场景】周三傍晚，快打烊，外面在下雨。你没带伞。
柜台上摊着一本没上架的旧书，扉页写着别人的名字。

【开场白】（他抬头看了眼窗外，又低头继续擦手里那本书的封面）
今天来得比平时晚。（把擦好的书放到一边，抽了张便签推过来）
外面雨大，伞在门后头，走的时候记得拿。……这本你别看，还没整理完。
```

注意最后一句「这本你别看」——它给了用户一个可以立刻违抗的钩子。**留一个用户能反着做的东西，比留一个问句更有效。**

## 你自己也是角色的一部分

只写对方是不够的。模型不知道「你」是谁，就只能把你当成一个没有面孔的提问者，对话自然浮在表面。

用户人设（persona）通常有两层：

- **账号级**：所有角色共用的默认设定。
- **角色级**（`user_persona`）：只在这个角色的对话里生效。同一个你，在旧书店老板面前是常客，在别处可以是别人。

写法和角色卡一样——具体行为优于形容词。「我不太会拒绝人」远好过「我性格软弱」。
