# 世界书（lorebook）怎么用

## 它解决什么问题

上下文是有限的。你的世界观可能有十万字设定，但每轮对话只能塞进去几千 token。全塞进角色卡不现实——挤掉对话历史，角色反而更容易失忆。

世界书的思路是**按需注入**：把设定拆成一条条，每条挂上关键词。**聊到才注入，不聊就不占地方。**

举例：你的设定里有二十个地名。用户提到「北境」时，只有北境那一条被塞进上下文，另外十九条安安静静待着。

## 触发机制

机制本身很简单，但它决定了所有的写法：

1. 系统扫描最近的对话内容
2. 命中某条的关键词 → 把该条内容插进上下文
3. 没命中 → 这条完全不存在

**所以关键词必须是对话里真的会出现的词。** 这是新手最常翻车的地方——关键词写成了你脑子里的分类名，而不是人物嘴里会说的话。

❌ 关键词：`北境地理`、`货币体系`、`主角背景设定`

没人会在对话里说「北境地理」。这几条永远不会被触发。

✅ 关键词：`北境`、`雪原`、`长城`｜`银币`、`铜板`、`多少钱`｜`你父亲`、`家里`、`小时候`

**写用户和角色真会说出口的词。** 一条可以挂多个关键词，尽量把同义说法、口语说法都覆盖到。

## 一条怎么写

关键在于：**世界书条目是给模型的提醒便签，不是百科词条。**

❌ 百科式：

```
北境是帝国最北端的行省，面积约四十万平方公里，人口一百二十万。
气候寒冷，年均气温零下三度。主要产业为畜牧与采矿。历史上曾三次
独立，分别在……（继续八百字）
```

✅ 便签式：

```
北境：终年积雪的边地。当地人管帝国叫「南边」，语气里没什么好感。
出门必须结伴，独行者活不过一个冬天。这里的人说话直，不兴客套。
```

区别在于：便签式的每一句都能**直接改变模型下一句怎么写**。人口一百二十万改变不了任何东西；「说话直，不兴客套」马上就能用上。

几条经验：

- **一条聚焦一件事。** 「北境」和「北境的宗教」拆成两条，各挂各的关键词。
- **控制长度。** 一两百字通常够了。写太长会挤掉对话历史，得不偿失。
- **写影响，不写数据。** 数字、面积、年表除非会被直接谈到，否则不必进。

## 什么留在角色卡，什么进世界书

一条简单的判断：**这个信息是「每轮都需要」还是「聊到才需要」？**

| 内容 | 放哪 | 为什么 |
|---|---|---|
| 角色的性格、说话方式 | 角色卡 | 每一句话都要用 |
| 角色和用户的关系 | 角色卡 | 每一轮都影响语气 |
| 角色的故乡长什么样 | 世界书 | 聊到才需要 |
| 十年前那场战争 | 世界书 | 可能整晚都不提 |
| 配角甲是谁 | 世界书 | 出场才需要 |

角色卡是常驻内存，世界书是按需加载。**角色卡塞不下的，多半都该进世界书。**

## 三个常见错误

**一、关键词太宽泛。** 挂上「他」「说」「人」这种词，等于每轮都触发，世界书退化成常驻内容，完全失去意义。

**二、条目之间打架。** A 条说领主宽厚，B 条说领主暴戾——两条同时被触发时，模型会自己编一个折中版本，通常两边都不像。**写完通读一遍，检查有没有互相矛盾的条目。**

**三、把世界书当剧情大纲。** 世界书是背景，不是脚本。写「主角最后会发现自己是王子」这种，模型可能提前几十轮就把它抖出来。
